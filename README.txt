SHAR CRYSTAL WATER — готовий проєкт

Файли:
- index.html — структура сторінки.
- styles.css — стилі й оформлення.
- assets.js — шляхи до зображень/відео.
- products.js — каталог товарів і ціни.
- app.js — логіка сайту.
- assets/images/ та assets/videos/ — медіафайли.

Як запустити у Windows:
1. Розпакуй ZIP у папку.
2. Відкрий Visual Studio Code.
3. Обери File → Open Folder і вибери папку SHAR-CRYSTAL-WATER.
4. Встанови розширення Live Server, якщо його ще немає.
5. Натисни правою кнопкою на index.html → Open with Live Server.
6. Сайт відкриється в браузері.

Важливо:
- Збережено оригінальний дизайн і клієнтський функціонал.
- Для стилів використовується Tailwind через CDN, тому потрібен інтернет.
- Це фронтенд-проєкт. Реальна багатокористувацька авторизація, синхронні замовлення, оплата й кабінети продавців потребують сервера та бази даних.
- Не видаляй assets.js або папку assets.
